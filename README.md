#  Blogger — Modern Developer Blog

A beautifully designed, fast, and SEO-optimized **Next.js blog** built with **TailwindCSS**, **Velite**, and **MDX**.  
Write, publish, and share articles effortlessly — from productivity hacks to advanced web development techniques.

##  Features

-  **Next.js 15** – App Router, optimized performance, and fast builds  
-  **TailwindCSS** – Fully responsive, elegant UI with utility-first design  
-  **Velite + MDX** – Write blog posts in Markdown/MDX format  
-  **Reading Time & Slug Generation** – Automatic metadata for every post  
-  **Dynamic Routes** – Clean URLs for blog posts and categories  
-  **SEO Ready** – Sitemap, manifest, meta tags, and OpenGraph support  
-  **Minimalist UI** – Focused reading experience with mindful aesthetics  
-  **Deployed on Vercel** – Instant previews and smooth CI/CD

##  Getting Started

### 1️ Clone the Repository
```bash
git clone https://github.com/rajanarahul93/Blogger.git
cd Blogger
````

### 2️ Install Dependencies

```bash
npm install
# or
yarn install
```

### 3️ Configure Environment Variables

Copy the example file and add your values:

```bash
cp .env.example .env.local
```

### 4️ Generate Content

```bash
npm run content
```

### 5️ Run Development Server

```bash
npm run dev
```

Your blog should now be running at **[http://localhost:3000](http://localhost:3000)**
